# Data-Summarization

 Lexi - Summarizer
 Lexi is a web-based application that uses natural language processing (NLP) to generate concise summaries from large blocks of text. It helps users extract the most important information quickly, making reading and comprehension more efficient.

🚀 Features
✅ Clean and responsive UI with TailwindCSS

📝 Paste or type any text to get an instant summary

🎛️ Adjust summary length using a slider

🌙 Supports dark mode for a better reading experience

📋 One-click copy functionality for summary output

🛠️ Built With
Flask – lightweight backend web framework

Python – core logic and summarization

NLTK / Transformers / Custom NLP Model – for text summarization

HTML + TailwindCSS – modern UI styling

JavaScript – interactivity and theme toggle
